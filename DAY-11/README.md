# Day 11 - Strings

# Problems Solved

## 1. Reverse a String

Reverse a given string using different approaches:

* **Method 1:** Reverse the string and store the characters in another string.
* **Method 2:** Use the two-pointer technique to swap characters.
* **Method 3:** Convert the string to an array, reverse it, and convert it back to a string.

**Note:** Practiced multiple approaches to understand different ways of manipulating strings.

## 2. Reverse the Words Present in a String

Reverse the order of words in a given string using different approaches:

* **Method 1:** Using built-in JavaScript methods.
* **Method 2:** Using recursion to reverse the words.

**Note:** Practiced string manipulation, recursion, and built-in methods.

# What I Learned

* Different techniques to reverse strings.
* How to use the two-pointer technique with strings.
* How to convert between strings and arrays.
* How to reverse words using built-in methods and recursion.
