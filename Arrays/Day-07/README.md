# Day 7 - Arrays

# Problems Solved

## 1. Sum of Elements in a Range (Prefix Sum)

Find the sum of elements between two given indices using the Prefix Sum technique to answer multiple range queries efficiently.

**Note:** Prefix Sum allows range sum queries without traversing the array every time.

## 2. Find Pivot Element in an Array

Find the pivot element where the sum of all elements to its left is equal to the sum of all elements to its right.

**Note:** If no such element exists, return an appropriate value or indicate that no pivot element is present.

## What I Learned

* How to use the Prefix Sum technique for range sum queries.
* How to solve multiple queries efficiently.
* How to find the pivot element in an array.
* Improved understanding of cumulative sums and array traversal.
